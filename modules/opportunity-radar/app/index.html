수집 출처 관리

공식 API·RSS로 자동 수집하는 출처와 직접 확인하는 출처를 관리합니다. 새 공고 수집을 누르면 연결된 공식 수집원에서 공고를 가져옵니다.

출처 등록 안내연결된 공식 수집원은 새 공고 수집 버튼으로 갱신됩니다. JSON API 또는 RSS 주소와 필요한 인증 정보를 등록하면 새 공고 수집으로 조회합니다. 웹사이트 첫 화면 주소만 등록하면 자동 수집할 수 없습니다.등록·삭제는 현재 브라우저에 저장됩니다. HTTPS 주소만 등록할 수 있습니다.
수집되지 않는 출처 연결에 필요한 정보

API: 실제 조회 주소, 수집 형식(JSON/XML), 서비스별 활용 승인과 인증키, 인증 파라미터 이름, 필수 조회 조건, 항목 경로가 필요합니다. RSS: 공식 HTTPS 피드 주소가 필요하며 일반적으로 인증키 없이 연결합니다.

K-Startup·국고보조금·중기부 API: 승인된 기본 주소를 등록했습니다. 상세 조회 경로 확인 후 자동 수집을 연결합니다. 중기부 RSS는 계속 수집됩니다. 판판대로는 활용 승인과 실제 조회 주소가 필요합니다. 관세청: CUSTOMS_SERVICE_KEY와 품목·국가·조회기간 설정이 필요합니다. 나라장터·기업마당이 연결됨 0건이면 인증 오류와 구분하여 조회기간·필터·응답 항목을 확인해야 합니다.

한국콘텐츠진흥원·국토교통 기업지원허브·보조금통합포털·민간기업 공지: 현재는 원문 링크입니다. 자동 수집하려면 제공기관의 공식 RSS/API 또는 데이터 제공 협의가 필요합니다.

공모전 모음: 위비티 · 씽굿 · 콘테스트코리아. 공개 RSS 주소는 확인되지 않았습니다. 공식 피드 또는 제휴 API를 제공받으면 연결할 수 있습니다.

API 키는 현재 페이지 메모리에만 두며 새로고침하면 사라집니다. 자동 수집은 HTTPS 공공기관 .go.kr 주소에서만 지원합니다. JSON은 제목 필드(title, pblancNm 등)가 있어야 공고로 등록됩니다.
실시간 연결 상태는 목록을 열 때 자동 갱신됩니다. API별 인증키와 제공 조건이 확인된 출처만 수집합니다. 로그인 정보나 비공개 접근은 수집하지 않습니다.
