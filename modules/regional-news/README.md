# 지역뉴스

archiveKR의 편집데스크에서 사람이 검토·발행한 기사를 읽는 신규 로컬 모듈입니다. 글로컬타임즈 참고 사이트의 코드나 데이터는 이전하지 않았습니다.

- `GET /api/news/articles`: 발행 기사 목록. `q`로 제목·본문·기관을, `region`으로 지역을 검색합니다. 최근 발행 순으로 정렬합니다.
- `GET /api/news/articles/:id`: 발행 기사 상세. 초안·검토 중 기사와 발행 취소 기사는 404를 반환합니다.
- `GET /api/news/briefing`: 현재 한국 날짜, 발행 기사 수, 기사 본문 앞 180자의 추출 요약. `규칙 요약`으로 표시합니다.

공개 응답은 질문 목록과 내부 검토 메타데이터를 제외합니다. 브리핑은 요청할 때 생성되며 예약 실행, LLM 요약, 자율 발행을 지원하지 않습니다. 발행 취소는 편집데스크에서 초안 상태로 돌리면 즉시 반영됩니다.

검증: `node --test modules/regional-news/server.test.mjs`
