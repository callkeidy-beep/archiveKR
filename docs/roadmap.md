# 단계와 실제 연결 상태

## 1단계
샘플20건·분류·근거 연결·후보12(탐색2)·편집자 평가. 점수는 규칙 기반이며 사실의 진위나 사진의 권리를 인증하지 않습니다. 같은 메일·수정본·엠바고·자료 부족을 숨기지 않습니다. 평가는 기사 승인/발행이 아닙니다.

## 이후 구현 목록 (아직 작동하지 않음)
- 2단계: 네이버/다음 IMAP SSL 접속시험, 읽기전용 BODY.PEEK, modified UTF-7, UID/UIDVALIDITY 복구·중복·수정본, 문서추출·한국어OCR·HWP, 암호화 저장·로그인·편집자 권한, 개인정보 가림, AI 공급자 어댑터, 근거대조 초안/수정이력
- 3단계: 다음날 규칙 가중치 조정/변경이력/복원, 최대10장 원고와 JSON/MD/NewsArticle JSON-LD 내보내기, 월요일03시 백업·외부저장·8주 보관·실제복원시험
- 4단계: IDLE 지원시험 후 선택기능, 상시 서버 배포·운영 검증, Instagram 게시 도입 검토. 지금은 SNS/SMTP를 보내지 않음
