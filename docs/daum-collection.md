# 다음메일 실제 수집·편집 작업대

무료 PC 로컬 실행을 지원합니다. 기존 다음 IMAP 접속 시험에 성공한 계정을 사용하며 관리자 로그인 후 직접 가져오기를 누릅니다. 자동 폴링·AI API·발송·게시 기능은 실행하지 않습니다. PC가 꺼지거나 프로그램을 종료하면 수집할 수 없습니다.

## Windows 업데이트

실행 중인 PowerShell에서 Ctrl+C로 서버를 멈춘 후 프로젝트 폴더에서 실행합니다.

```powershell
git pull --ff-only origin main
.\.venv\Scripts\python.exe -m app.run
```

브라우저를 강력 새로고침(Ctrl+F5)하고 연결·설정에서 기존 관리자 비밀번호로 로그인합니다. **실제 메일 가져오기** 후 **실제 메일 작업대 열기**로 이동합니다. 샘플로 돌아가기 버튼은 실제 메일을 삭제하지 않습니다. 로그아웃하면 실제 자료 표시를 지웁니다.

## 범위와 주의

- 설정한 폴더만 읽으며 EXAMINE과 BODY.PEEK를 사용합니다. 메일을 읽음으로 바꾸거나 이동·삭제하지 않습니다.
- 첫 수집은 폴더별 최근 20건으로 시작합니다. 이후 가져오기는 신규 메일과 이전 메일을 나누어 폴더별 최대 20건씩 추가합니다. 반복하면 과거 자료도 가져올 수 있습니다. 보관 한도는 500건 또는 암호화 전 약 32MiB이며 초과 시 오래된 보관 자료를 정리합니다. 메일 서버의 원본은 삭제하지 않습니다.
- 제목·발신자·수신 시각·텍스트 본문으로 키워드 분류와 규칙 기반 후보 점수를 만듭니다. 점수는 편집 판단을 대신하지 않습니다.
- HTML은 텍스트로 변환합니다. 외부 이미지·링크를 열지 않습니다. 첨부는 목록과 수동 확인 표시만 제공하며 파일 추출·OCR은 미구현입니다.
- 대용량·읽을 수 없는 자료는 수동 확인이 필요합니다. 엠바고 문구가 감지되면 시간을 자동 추측하지 않고 보수적으로 송고 보류합니다. 원문을 직접 확인하세요.
- 수집 자료와 평가는 서버의 비공개 암호화 파일에 저장합니다. 공개 샘플 JSON, GitHub Pages, 브라우저 localStorage, AI 서비스로 보내지 않습니다.
- 암호화 키와 데이터가 있는 `.local` 폴더를 공개하거나 Git에 추가하지 마세요. Windows 로컬 키 파일은 PC 자체 침해까지 막는 장치는 아닙니다. Windows 계정 접근과 디스크 보안을 함께 관리하세요.

실제 접속 성공은 사용자 PC에서만 확인할 수 있습니다. 개발 테스트는 가짜 IMAP 응답을 사용하며 실제 계정 접속 성공을 뜻하지 않습니다.
