03 / TIMES

—작성 중

—발행 기사
현재 연결 범위

기회탐색은 원본 기회레이더를 재사용했습니다. 취재·편집과 지역뉴스는 이 프로젝트에서 새로 만든 기능이며, 기존 두 사이트의 데이터는 아직 이전되지 않았습니다. 로그인·직원 권한과 운영 배포는 별도로 연결해야 합니다.

DISCOVER / 기회탐색

공모 지원사업 탐색

실제 수집은 기존 기회레이더 서버의 공개 API를 중계합니다. 새 환경으로 인증키를 옮긴 것은 아닙니다. 상세 화면에서 기사 기획으로 인계하고, 시연 공고와 실제 공고를 구분해 원문을 확인하세요.

WRITE / 취재·편집

취재·편집 데스크

초안 → 검수 대기 → 발행. 발행 원고는 초안으로 되돌린 뒤 수정합니다. 현재 작업자는 로컬 사용자이며 별도 승인자 계정은 없습니다.

PUBLISH / 지역뉴스

지역의 오늘을 기록합니다.

로컬 데스크에서 발행한 기사만 표시됩니다. 외부 사이트에 자동 게시되지 않습니다.

CREATE / 영화·카드뉴스

영화·카드뉴스 제작실

첨부 MOVIST 규격과 원본 제작 도구를 재사용합니다. 카드 이미지 제작은 로컬에서 실행되며, AI 원고 작성은 별도 인증키가 필요합니다. 외부 채널에는 자동 게시되지 않습니다.
